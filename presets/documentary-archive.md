# Preset — Documentary Archive

```text
Name:        documentary_archive
Best For:    历史 / 品牌故事 / 人物纪实 / 社会议题 / 长视频叙事（Production Mode B）
Difficulty:  3 / 5（素材治理与版权核验要求高）
Energy:      2 / 5（沉稳、真实、有重量）
Tempo:       慢-中（叙事段 0.9x，情绪段 0.7x）
Origin:      总设计 v0.2 §8「Documentary / Archive」固定选项之一
```

## Visual Character

像被时间抚摸过的影像档案：胶片颗粒、轻微划痕、暗角与老旧素材混合，真实感是第一优先级。画面的主体是"证据"——历史影像、档案照片、信件、地图、现场实录，图形层只做最小干预（标注时间地点、圈出关键人物），让素材自己说话。整体气质是克制与可信：宁可信息少而真，不可修饰多而假。观众看到的不是"一条视频"，而是一册被认真整理过的历史档案。

## Composition

以素材原构图为主，不强加网格：老照片、录像、信件以"档案陈列"方式呈现（居中或成组挂放，带细边框与标签）。图文标注使用档案馆风格（白色小字 + 时间戳 + 档案编号）。新拍素材与老素材通过统一处理（颗粒 / 色罩）混成一体。构图允许"不完美"，但必须稳定——手持晃动仅在真实记录场景中出现。

## Typography

衬线字体（如档案字体 / 报纸体）为主，标题级字重偏大、克制使用。时间地点标注用等宽或打字机风格小字，与档案语言一致。字幕采用报纸体或干净无衬线，避免现代感过强的圆体。文字出现频率低，主要功能是"为素材提供上下文"而非讲解动画。

## Motion

动效主要应用于"让静态档案活起来"：老照片缓慢推近（Ken Burns）、扫描线过屏、档案翻页、地图线条生长、手写笔迹浮现。运动幅度小、速度慢，模拟"审视档案"的动作。Narrative Motion 用于时间线推进与因果揭示。全片几乎没有快节奏动效，节奏由剪辑本身承担。

## Camera

实拍段落采用纪实运镜：手持轻晃（真实感）、缓慢摇摄、固定机位长镜头。档案段落相机极克制：缓慢推拉与平移（Ken Burns 逻辑）。允许"素材间跳切"这一纪录片语言。相机情绪稳定，只在关键情绪点（如亲历者讲述）做一次缓慢推近以示"进入内心"。

## Lighting

实拍以自然光 / 现场光为主，不做强力布光；暗部保留细节、高光柔和。档案素材保持原有影调，统一加轻颗粒与色罩（暖棕 / 冷灰二选一）让不同来源素材同频。避免高饱和与强对比，整体影调像"冲洗过的相纸"。

## Materials

素材介质本身就是材质：胶片颗粒、纸张纤维、旧印刷网点、磁带噪点。图形层以"档案工具"为材质：图钉、胶带、回形针、手写标签。数字转场（如有）必须克制——多以硬切或胶片式闪白过渡，不用玻璃拟态等现代 UI 材质。

## Footage

真实素材是绝对主体：档案视频、老照片、亲历者访谈、实地空镜。素材来源必须记录（归档编号 / 来源 / 版权 / 授权），并在项目记忆 asset-memory 中登记。AI Video 在本风格中极谨慎使用——只用于"无法获得且必须呈现"的历史场景示意，且画面需有明确"再现"标识（如淡褐色 + 边框 + "示意"水印），防止观众误认为真实史料。

## Audio Relationship

声音以"在场感"为设计：环境声（街市、房间、纸张、脚步）承担大量叙事，配乐克制、以环境音 / 弦乐 / 钢琴低音量铺底。访谈人声是最重要声轨，绝不压过。历史段落用旧音频质感（留声机 / 广播）做时代提示。静默被认真使用——真实素材与停顿是情绪的一部分。

## Hero Effects

配额：≤ 2 处，且必须服务于叙事高点。典型如"档案的真相时刻"：一段原本静态的老照片在关键讲述处缓慢放大，照片中的某个细节（如一个背影）在颗粒中浮现为动态影像（素材重演），配以音色的突然展开。Hero 效果的本质是"证据被激活"，不是光效堆叠。

## Why works

真实素材自带"不可反驳性"，适合需要信任与情感重量的内容；档案陈列美学在长视频中不疲劳，且让信息记忆更深刻；制作上对拍摄依赖低、对素材治理要求高，可编辑性强（素材即资产）。

## What to avoid

避免过度滤镜化让真实素材失真（观众一旦察觉就失去信任）/ 避免 AI 生成影像冒充真实史料（必须标识）/ 避免现代 UI 元素（玻璃拟态、圆角卡片）混入档案语境 / 避免配乐压过人声 / 避免"每张照片都要动起来"（静态也是档案的真实）。

## Typical Scene

**Scene：老照片的重逢（人物纪实中段）**。黑屏中以打字机声浮现一行档案编号，随后一张发黄的老照片从暗处缓缓显现（3% 颗粒 + 轻微划痕），照片中是四十年前的教室。旁白讲述主人公的回忆时，相机以每秒 2px 的速度缓慢推近照片中一个模糊的人影；配乐只剩下极轻的钢琴单音与环境纸声。讲述到"那就是他第一次见到老师"的瞬间，照片静止 2 秒，随后硬切到今天的教室实拍空镜（同一机位感），观众通过剪辑感受到时间跨越。全段 40 秒，仅一次推进动效。
