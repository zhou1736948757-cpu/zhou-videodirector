# Preset — Editorial Explainer

```text
Name:        editorial_explainer
Best For:    科技科普 / 财经解读 / 产品教育 / 5-10min 长视频（Production Mode B）
Difficulty:  3 / 5（信息组织要求高，视觉实现中等）
Energy:      3 / 5（清晰、节奏化、有推动力）
Tempo:       中-快（章节节奏 1.05x，信息密集段 1.1x，解释段 0.9x）
Origin:      总设计 v0.2 §8「Editorial Explainer」固定选项之一；对应 Production Mode B（剪映主时间线）
```

## Visual Character

一本"能被看完"的会动杂志：信息永远被组织成清晰的编辑单元——章节标题、要点卡片、图表、图解、地图依次登场，像翻一本结构严谨的杂志。画面不追求单一华丽风格，而追求"信息密度可控 + 每 5-10 秒一个新刺激"。底色多浅色 / 米白 / 低饱和，图形语言统一（一致的圆角、图标风格、图表样式），让长视频的每个章节都"看起来是同一本书"。核心气质是"把复杂讲明白"的可靠感。

## Composition

以编辑排版为核心：标题区 + 内容区 + 脚注区的固定版式；图文并排（左文右图 / 上题下图）为主。每章有统一的章节页（章节号 + 章题 + 预告），章节内部用一致的卡片模板组织信息。视觉重心随阅读动线（从上到下、从左到右）运动，用低透明度引导线或光标指示"正在读哪里"。

## Typography

无衬线为主，标题与正文层级清晰，数字与单位使用等宽字体。强调方式为"字号 + 颜色 + 加粗"三选一，避免同时使用。行宽控制在 45-70 字符，长句必须被切段。关键术语首次出现时带 tooltip 式注解。字幕与画面文字共用一套字体规范，保证长视频的阅读一致性。

## Motion

动效服务"信息进场"：卡片依次入场、图表数据增长、章节过渡（整页翻动 / 章节横幅拉入）。运动基准 250-350ms、ease-out，批量信息用 stagger（依次延迟 40-60ms）。Narrative Motion 出现在关键解释处（如因果图连线、时间轴推进），全片 Hero 极少。长视频靠"持续但可预期"的动效维持节奏，不追求单帧惊艳。

## Camera

相机以"出版物视口"为主：视口在页面间平移、缩放（推入卡片 / 拉出总览），像在杂志上进行 PPT 式运镜。允许小幅视差营造 2.5D。长视频中运镜服务于章节结构：章首推入、章尾拉出，让观众感知"这一章结束了"。

## Lighting

无叙事性光影，以"编辑台灯光"为准：平坦、均匀、明亮，确保文字对比度。卡片与背景靠明度与描边区分，不靠阴影。局部高光仅用于高亮当前讲解区块。整体明亮度在长视频中维持恒定，避免观众疲劳。

## Materials

平面材质为主：卡片、纸张、白板、胶带、便利贴。允许少量 3D（数据图表、地图、模型旋转）但需与平面语言统一调色。背景常用"编辑工作台"意象（桌面、网格纸、目录卡）承载章节感。

## Footage

真实素材（B-roll / 人物访谈 / 实地镜头）大量使用，承担"证明与共情"；图形层叠加其上做标注与强调（画框、箭头、数值）。B-roll 统一调色为低饱和暖调。AI Video 只用于无法实拍的概念示意，且必须打上"示意图"视觉约定（如统一边框）防止误导。

## Audio Relationship

音乐以"低干扰背景 + 章节切换 cue"为设计：全程维持中性氛围音乐，章节边界有明显音乐变化提示结构；SFX 使用 UI 化提示音（whoosh / click / data pulse）标注信息点。旁白是主导声轨，音乐与 SFX 在旁白下 ducking。长视频的听觉目标是"可听 10 分钟不累"。

## Hero Effects

配额：全片 2-4 处，集中在章节高潮 / Payoff。典型如"一张复杂图表在关键时刻由局部展开为全景"或"时间轴在第 7 分钟一次性揭示全局因果链"。Hero 效果服务于"理解达成"的瞬间，而非视觉炫技。每个 Hero 前必须有约 20-30s 的信息积累。

## Why works

编辑结构让 5-10 分钟的信息可被逐段消化，配合章节 cue 让观众时刻知道"讲到哪了"；统一图形语言让多来源素材（B-roll / 图表 / AI 示意）看起来是一个系统，可信度来自一致性；动效可预期、音量克制，支持长时间注意力。

## What to avoid

避免每 5 秒一个转场（长视频会眩晕）/ 避免信息密度失控（单屏超过 3 个要点即超载）/ 避免图形风格在章节间漂移 / 避免 Hero 效果过度（两次间隔小于 20s）/ 避免旁白与字幕逐字重复（应互补而非复读）。

## Typical Scene

**Scene：第二章开篇（8min 科普）**。章节横幅从左侧拉入：白色背景上一排目录卡片，第二章高亮放大，其余章节退为 40% 透明度。相机推入第二章标题卡，下方依次浮现三张要点卡片（每张间隔 60ms 入场），每张卡片旁配一个小图标。旁白讲第一要点时，对应卡片下方延展出折线图并开始增长，坐标刻度逐格亮起，配以 data pulse 音效。全段 25 秒，动效全是"信息跟随讲解"的编辑语言，无任何无关特效。
